# PE07 – Restaurant Class Assignment

In this lab, I created a Python class called Restaurant. The class stores two main pieces of information: the restaurant’s name and its cuisine type. I also added two methods: one that prints a description of the restaurant and another that prints a message showing that the restaurant is open.

For this assignment, I created three restaurant objects:
- Pho_Tuan (Vietnamese)
- Sushi_House (Japanese)
- Pizza_Palace (Italian)

This lab helped me understand how to define a class, use the __init__ method, store attributes with self, and create multiple objects from the same class.
